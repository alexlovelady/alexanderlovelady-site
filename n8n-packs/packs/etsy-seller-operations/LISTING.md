# Listing: Etsy Seller Operations

**Title:** n8n Etsy Seller Operations Automation | Order Queue, Ship-By Alerts, Expense Log, Low Stock, Weekly Summary

**Price tests:** Lite $29 / Pro $49

**Description:**

Never miss a ship-by date, and know your numbers every Monday, from one Google Sheet. This n8n pack gives you 7 importable workflows for etsy and handmade-goods sellers who run orders from a spreadsheet.

INCLUDED
- Log An Order
- Mark Order Shipped
- Ship-By Queue
- Log An Expense
- Low Stock Alert
- Weekly Shop Summary
- Error alert workflow
- Google Sheets header templates
- Step-by-step README and sample requests
- Built-in dry-run mode so you can test without sending anything

GOOD TO KNOW
- This pack does NOT call the Etsy API (it requires an approved developer app). Orders enter through the `etsy-order` webhook (send from Zapier/Make, a form, or a script) or by pasting rows into the sheet.
- It sends no emails to buyers. Use Etsy's own messaging for buyer communication to stay within Etsy's rules.
- Profit figures are only as accurate as the expenses you log, and are not tax advice.

REQUIREMENTS: n8n (self-hosted or Cloud) and a Google account. Tested on n8n 2.42.5. This is a template, not a managed service.

**Do not claim:** sales, reviews, guaranteed results, endorsement by n8n/Google/Stripe/Shopify/Anthropic, or that it was tested with live accounts (it was not).
