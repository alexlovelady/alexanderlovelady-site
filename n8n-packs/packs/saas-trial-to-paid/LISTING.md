# Listing: SaaS Trial-to-Paid Lifecycle

**Title:** n8n SaaS Trial-to-Paid Automation | Welcome Email, Onboarding Nudges, Trial-Ending Reminders, Churn Survey

**Price tests:** Lite $39 / Pro $69

**Description:**

Turn more trials into customers with timely, plain-text emails driven by your own signup data. This n8n pack gives you 8 importable workflows for micro-saas owners and indie founders.

INCLUDED
- New Trial Signup
- Onboarding Nudges
- Trial Ending Reminders
- Converted To Paid
- Cancelled Or Churned
- Mark User Activated
- Weekly Conversion Report
- Error alert workflow
- Google Sheets header templates
- Step-by-step README and sample requests
- Built-in dry-run mode so you can test without sending anything

GOOD TO KNOW
- Your app calls the webhooks: `saas-signup` when a trial starts, `saas-activated` when the user hits your activation moment, `saas-converted` and `saas-cancelled` from your billing events.
- Onboarding and reminder emails go only to users with status `trial`, so converted and churned users stop getting them.
- Marketing-style emails carry an opt-out line. Set `opted_out` = `yes` when someone replies STOP.

REQUIREMENTS: n8n (self-hosted or Cloud) and a Google account. Tested on n8n 2.42.5. This is a template, not a managed service.
