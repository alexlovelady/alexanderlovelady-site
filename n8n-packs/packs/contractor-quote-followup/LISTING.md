# Listing: Contractor Quote & Follow-Up

**Title:** n8n Contractor Quote & Follow-Up Automation | Estimate Requests, Auto Follow-Ups, Job Handoff | Google Sheets + Gmail

**Price tests:** Lite $29 / Pro $59

**Description:**

Every estimate request answered the same day, and every quote followed up until it's won or closed. This n8n pack gives you 6 importable workflows for remodelers, electricians, plumbers, roofers and other trades that quote jobs.

INCLUDED
- Estimate Request Intake
- Quote Follow-Ups
- Quote Accepted
- Requests Waiting For A Quote
- Weekly Pipeline Report
- Error alert workflow
- Google Sheets header templates
- Step-by-step README and sample requests
- Built-in dry-run mode so you can test without sending anything

GOOD TO KNOW
- Quotes are not generated by this pack. You send your quote the way you do today, then set `status` to `quoted` and fill `quote_sent_at` in the sheet to start follow-ups.
- Follow-ups stop automatically when status changes (accepted, lost) or when you set `opted_out` to `yes` after someone replies STOP.
- Different trades can be routed to different people by editing `estimators` in the Config node.

REQUIREMENTS: n8n (self-hosted or Cloud) and a Google account. Tested on n8n 2.42.5. This is a template, not a managed service.
