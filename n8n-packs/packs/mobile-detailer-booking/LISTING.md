# Listing: Mobile Detailer Booking Assistant

**Title:** n8n Mobile Auto Detailer Booking Automation | Booking Requests, Deposit Reminders, Appointment Reminders, Reviews

**Price tests:** Lite $29 / Pro $49

**Description:**

Fewer no-shows and unpaid slots, with zero manual reminders. This n8n pack gives you 7 importable workflows for mobile and shop-based auto detailers.

INCLUDED
- Booking Request Intake
- Confirm Booking
- Deposit Reminders
- Appointment Reminders
- Thank You And Review Request
- Weekly Bookings Report
- Error alert workflow
- Google Sheets header templates
- Step-by-step README and sample requests
- Built-in dry-run mode so you can test without sending anything

GOOD TO KNOW
- Deposits are collected through YOUR payment link (Stripe, Square, PayPal, etc.). Mark `deposit_paid` = `yes` in the sheet when it arrives to stop reminders.
- Statuses used: requested, booked, completed. Set `completed` after the job to trigger the thank-you/review email.
- The review email goes to every completed customer. Do not change it to send only to happy customers.

REQUIREMENTS: n8n (self-hosted or Cloud) and a Google account. Tested on n8n 2.42.5. This is a template, not a managed service.

**Do not claim:** sales, reviews, guaranteed results, endorsement by n8n/Google/Stripe/Shopify/Anthropic, or that it was tested with live accounts (it was not).
