# Listing: Restaurant Catering Inquiry Funnel

**Title:** n8n Catering Inquiry Automation | Event Inquiries, Date & Capacity Checks, Proposal Follow-Up, Deposit Reminders, Prep List

**Price tests:** Lite $29 / Pro $49

**Description:**

Reply to every event inquiry the same day, decline impossible dates politely, and chase proposals and deposits automatically. This n8n pack gives you 7 importable workflows for caterers and restaurants that take event orders.

INCLUDED
- Event Inquiry Intake
- Proposal Follow-Ups
- Event Confirmed
- Deposit Reminders
- Event Countdown
- Upcoming Event Prep List
- Error alert workflow
- Google Sheets header templates
- Step-by-step README and sample requests
- Built-in dry-run mode so you can test without sending anything

GOOD TO KNOW
- Blackout dates, maximum guests and minimum lead time are set in the Config (`blackout_dates`, `max_guests`, `min_lead_days`). Edit them.
- The pack checks only those three rules. It does not read your calendar for double-bookings; review `new` inquiries before quoting.
- Dietary and allergy information is copied from the customer. It does not replace your own allergen process.
- Deposit payment instructions are text in the Config. Payment is handled by your own invoicing/payment tool.

REQUIREMENTS: n8n (self-hosted or Cloud) and a Google account. Tested on n8n 2.42.5. This is a template, not a managed service.
