# Listing: Appointment No-Show Reduction

**Title:** n8n Appointment No-Show Reduction Automation | Confirmations, Reminders, Reschedule, Missed-Appointment Follow-Up

**Price tests:** Lite $29 / Pro $39

**Description:**

Reminders that actually reduce no-shows, with a one-click reschedule path. This n8n pack gives you 8 importable workflows for salons, tutors, coaches, clinics and other appointment-based businesses.

INCLUDED
- New Appointment
- Appointment Reminders
- Mark No-Show
- Mark Attended
- Reschedule Appointment
- Missed Appointment Follow-Up
- Weekly No-Show Report
- Error alert workflow
- Google Sheets header templates
- Step-by-step README and sample requests
- Built-in dry-run mode so you can test without sending anything

GOOD TO KNOW
- After each appointment, mark it attended or no-show (webhook or the sheet's `status` column). The pack only reports what you record.
- Reminders run once daily in the afternoon: 2 days before and 1 day before. They cannot target an exact hour.
- No deposits or fees are charged by this pack. If you have a cancellation policy, state it in your own terms and in the Config wording.

REQUIREMENTS: n8n (self-hosted or Cloud) and a Google account. Tested on n8n 2.42.5. This is a template, not a managed service.
