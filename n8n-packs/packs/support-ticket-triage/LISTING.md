# Listing: Customer Support Triage

**Title:** n8n Customer Support Triage Automation | Ticket Intake, Auto-Categorize, SLA Dates, Draft Replies, Breach Alerts

**Price tests:** Lite $39 / Pro $69

**Description:**

Every request logged, categorized and prioritized, with a draft reply waiting for your review. This n8n pack gives you 5 importable workflows for small saas companies and help desks without a ticketing system.

INCLUDED
- Ticket Intake And Triage
- Update Ticket
- SLA Breach Watch
- Weekly Support Report
- Error alert workflow
- Google Sheets header templates
- Step-by-step README and sample requests
- Built-in dry-run mode so you can test without sending anything

GOOD TO KNOW
- Categories and priorities come from KEYWORD RULES (no AI), which you can read and edit in the intake Config (`tags`). They are a first pass and will sometimes be wrong; the sheet's category/priority columns can be corrected by hand.
- Reply DRAFTS are created in Gmail for a human to edit and send. Nothing but the receipt is sent automatically. Placeholders like [WRITE YOUR REPLY] must be replaced before sending.
- The receipt promises a response target (`sla_hours` in Config). Set realistic hours; only promise what you can meet.
- SLA dates have daily granularity. The breach watch runs twice on weekdays.

REQUIREMENTS: n8n (self-hosted or Cloud) and a Google account. Tested on n8n 2.42.5. This is a template, not a managed service.
