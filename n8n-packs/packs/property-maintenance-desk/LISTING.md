# Listing: Property Manager Maintenance Desk

**Title:** n8n Property Maintenance Request Automation | Tenant Requests, Urgency Routing, Contractor Alerts, Status Updates

**Price tests:** Lite $29 / Pro $59

**Description:**

Every tenant request logged, routed to the right contractor and answered, with emergencies escalated instantly. This n8n pack gives you 5 importable workflows for small landlords and property managers.

INCLUDED
- Maintenance Request Intake
- Update Request
- Completion Survey
- Open Request Aging
- Error alert workflow
- Google Sheets header templates
- Step-by-step README and sample requests
- Built-in dry-run mode so you can test without sending anything

GOOD TO KNOW
- SAFETY: the emergency reply tells tenants to call 911 first for danger. This pack is NOT an emergency service and must never be the only way tenants can reach you in an emergency. Keep a phone line monitored.
- Contractors listed in `contractors` receive the tenant's name, phone and request details. Only add contractors you trust, and follow your local privacy and landlord-tenant rules.
- Edit the `category` list and routing map in the Config to match your trades.
- Statuses used: open, scheduled, in_progress, completed, cancelled. Completed requests trigger a next-day survey email.

REQUIREMENTS: n8n (self-hosted or Cloud) and a Google account. Tested on n8n 2.42.5. This is a template, not a managed service.
